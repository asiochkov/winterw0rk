# WINTERWORK — MOTION ONLY PACK

This pack contains ONLY the motion/animation layer for Winterwork.

It intentionally excludes:
- product UX audit;
- UI kit;
- design system;
- current project source;
- screenshots;
- unrelated references.

Use this pack together with the existing Winterwork project.

## Goal

Make Winterwork feel:
- premium;
- fluid;
- tactile;
- spatial;
- cinematic at meaningful moments;
- fast during everyday use.

Motion must improve comprehension and feedback without taking attention away from the product.

## Reference direction

- Linear — precision and micro-interactions
- Arc / Arc Search — spatial transitions
- Apple Fitness — progress and tactile feedback
- Strava — data storytelling
- Headspace — calm rhythmic motion

Do not copy branding, assets or exact interfaces.

## Claude Design workflow

1. Read the existing Winterwork project.
2. Read this entire pack.
3. Implement the motion system and reusable motion primitives.
4. Apply the screen-specific motion map.
5. Run the motion QA checklist.
6. Do a final consistency/performance pass.

Do not redesign product UX or rebuild business logic as part of this task.

# WINTERWORK — ACCEPTANCE CRITERIA

## Product integrity
- All 24 known product areas remain represented.
- No core action is removed.
- No primary flow becomes longer without a clear UX reason.
- Navigation remains predictable.

## UX
- Every screen has one primary purpose.
- Every screen has an obvious next action.
- High-frequency actions are fast.
- Error states explain recovery.
- Empty states explain what to do.
- Offline state is understandable.
- Destructive actions are protected.
- Undo exists for reversible actions where appropriate.

## UI
- One coherent component language.
- Consistent radii.
- Consistent typography.
- Consistent iconography.
- Consistent status grammar.
- Accent is restrained.
- Glass is selective.
- No generic purple AI gradient.
- No random component variants.

## Responsive
- Desktop is spatial.
- Mobile is priority-driven.
- Tablet is intentionally compressed.
- Active workout remains usable with one hand.
- Focus remains immersive.

## Accessibility
- Focus visible.
- Touch targets ~44px or larger.
- Status not communicated only by color.
- Readable contrast.
- Logical focus order.
- Reduced motion respected.

## Visual quality
- The first impression is premium.
- The interface has depth without visual noise.
- The product has a recognizable Winterwork identity.
- The design is not a clone of any external kit.

## Final question

If a user opens the app for the first time, can they answer within seconds:

**Where am I?**
**What matters?**
**What should I do?**
**What happened after I did it?**

If not, the redesign is not finished.

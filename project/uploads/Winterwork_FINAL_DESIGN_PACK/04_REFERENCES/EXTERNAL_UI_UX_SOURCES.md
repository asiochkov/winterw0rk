# EXTERNAL UI / UX SOURCE MAP

## UI KIT 01 — Untitled UI
Official: https://www.untitledui.com/free-figma-ui-kit
Role in Winterwork: component quality, spacing, typography, interaction states, responsive patterns.

Take principles for:
- buttons;
- inputs;
- navigation;
- cards;
- tabs;
- badges;
- progress;
- charts;
- modals/sheets;
- form states;
- accessibility.

Do NOT copy Untitled UI's visual identity.

## UI KIT 02 — Obra shadcn/ui Community
Official: https://shadcn.obra.studio/
Role in Winterwork: implementation-minded component architecture, variables, variants, dark/light structure, consistent primitives.

Take principles for:
- component variants;
- state management;
- tokens;
- reusable primitives;
- composability.

Do NOT make Winterwork look like generic shadcn.

## UX RESEARCH — Mobbin
Official: https://mobbin.com/
MCP: https://mobbin.com/mcp
Role: inspect real-world user flows and shipped interaction patterns.

Research categories:
- onboarding;
- habit/task creation;
- fitness/workout;
- timers;
- progress;
- paywalls;
- settings;
- search/filter;
- empty/error/recovery.

Never copy a competitor's screen wholesale.

## UX TOOLKIT
Official: https://www.antforfigma.com/ux-toolkit-for-figma
Role: information architecture, wireframes, user-flow planning and documentation.

If unavailable, use `02_UX` in this package as the authoritative replacement.

## IMPORTANT

Claude Design officially supports attaching/importing one or several design systems from design files, raw uploads, GitHub or local codebases, and recommends complete systems containing styles, fonts and components. Use the external kits as additional context; the Winterwork system in this package remains the final authority.

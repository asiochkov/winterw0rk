# WINTERWORK — FINAL DESIGN / UX MASTER PACK

This package is the single source of truth for redesigning the existing Winterwork product in Claude Design.

## What this package is for

Do NOT treat this as a moodboard or a prompt-only exercise.
The objective is to produce a **finished, coherent, premium Winterwork product concept** with a complete UX architecture and a production-minded UI system while preserving the existing product's functionality.

## SOURCE PRIORITY

1. **Existing Winterwork product/code** — source of truth for functionality.
2. **Winterwork references in `04_REFERENCES`** — source of truth for desired atmosphere and visual direction.
3. **`02_UX`** — source of truth for interaction, information architecture and user-flow decisions.
4. **`03_UI`** — source of truth for the proposed Winterwork component/design system.
5. **External UI kits** — reference material only. Never copy their identity wholesale.

## The two UI systems to use as external references

- Untitled UI Free Figma UI Kit: https://www.untitledui.com/free-figma-ui-kit
- Obra shadcn/ui Community Figma Kit: https://shadcn.obra.studio/

These should be imported/attached in Claude Design if available. They are not redistributed in this package.

## UX research references

- Mobbin: https://mobbin.com/
- Mobbin MCP: https://mobbin.com/mcp
- UX Toolkit for Figma: https://www.antforfigma.com/ux-toolkit-for-figma

Use these as research references, not as sources to copy wholesale.

## NON-NEGOTIABLE OUTCOME

The result must not be a repaint of the existing app.
It must be a **product-level redesign**:

UX architecture → flows → information hierarchy → design system → screens → states → responsive behavior → motion → QA.

The result should feel expensive, calm, precise, distinctive and immediately understandable.

## Files

- `01_SOURCE`: original Winterwork project and inventory.
- `02_UX`: complete UX architecture, audits, flows, heuristics, state matrix and edge cases.
- `03_UI`: Winterwork-specific design system, tokens, component contracts and Figma-ready visual board.
- `04_REFERENCES`: existing visual references supplied with the project.
- `05_CLAUDE`: execution prompt and staged operating instructions.
- `06_FIGMA_READY`: SVG boards that can be imported into Figma or supplied directly as reference assets.
- `07_QA`: final acceptance criteria and regression checklist.

## IMPORTANT

Claude should first understand and reconcile the product, then design. It should not blindly redesign screen-by-screen.

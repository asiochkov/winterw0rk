# WINTERWORK — STATE MATRIX

Every important component and screen must explicitly handle relevant states.

## Universal states

1. Default
2. Hover
3. Focus
4. Pressed
5. Selected
6. Disabled
7. Loading
8. Success
9. Error
10. Empty
11. Offline
12. Locked/premium
13. Undo available
14. Destructive confirmation
15. Validation error
16. Partial completion
17. Sync pending

## Accessibility state requirements

Never communicate a meaningful state through color alone. Pair color with icon, label, shape, text, or position.

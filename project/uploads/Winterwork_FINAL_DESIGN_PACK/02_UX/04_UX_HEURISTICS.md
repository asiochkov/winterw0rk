# WINTERWORK — UX HEURISTICS / DECISION RULES

## H1 Visibility of system status
After every meaningful action, show immediate feedback.

## H2 Match the user's mental model
Use everyday terms: complete, pause, resume, skip, edit, save, undo.

## H3 User control
Reversible actions should not require confirmation. Destructive actions should.

## H4 Consistency
A habit completion, workout completion and focus completion should share the same feedback grammar even if their visual components differ.

## H5 Error prevention
Disable impossible actions and validate before destructive operations.

## H6 Recognition over recall
Expose context and current state. Do not require users to remember where they were.

## H7 Progressive disclosure
Basic action first. Advanced configuration second.

## H8 Efficiency
High-frequency operations must be one or two interactions where reasonable.

## H9 Minimalism
Remove information that does not support a decision or task.

## H10 Recovery
Every error should provide a path forward.

## H11 Accessibility
Keyboard, touch, contrast, focus and semantic status must be first-class.

## H12 Emotional tone
Discipline is not punishment. Failure states should be neutral, factual and recovery-oriented.

## Anti-patterns forbidden

- mystery meat navigation
- card soup
- infinite dashboard stacking
- modal for every action
- giant decorative hero on task screens
- tiny touch targets
- hidden primary actions
- color-only status
- generic motivational quotes replacing useful information
- excessive glassmorphism
- excessive gradients
- excessive glow
- animation that delays a task

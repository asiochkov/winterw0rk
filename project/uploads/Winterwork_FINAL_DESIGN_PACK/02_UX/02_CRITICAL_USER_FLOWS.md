# WINTERWORK — CRITICAL USER FLOWS

## 1. FIRST-RUN ONBOARDING

Welcome → Sign in/Create account → Personalization → Goal → Schedule/constraints → Confirmation → Today

Rules:
- Progress indicator must explain remaining effort.
- Every question needs a reason or useful framing.
- Allow back without data loss.
- Avoid asking for low-value data before the user sees value.
- Never make onboarding feel like a form.
- Finish by showing a personalized Today, not a generic dashboard.

## 2. DAILY LOOP

Today → identify next action → perform action → instant feedback → Today recalculates → next action

Primary principle: the user should not have to manually reconcile completion with progress.

## 3. HABIT CREATION

Habits → Add → name/type → schedule → reminder (optional) → save → immediate appearance in Today/Habits

Editing a habit must preserve history unless the user explicitly changes the semantic identity of the habit.

## 4. HABIT COMPLETION

Today/Habits → tap completion → immediate completed state → optional undo → progress update

No confirmation dialog for reversible completion.

## 5. QUIT / RELAPSE

Quit → craving/log relapse → consequence preview → confirm only when needed → recovery state → updated streak/history

Never shame the user. Recovery must be actionable and calm.

## 6. MOOD

Mood → choose state → optional note → save → feedback/insight

Keep the basic check-in fast. Advanced influence factors remain secondary/premium.

## 7. FOCUS

Focus → duration/preset → Start → active timer → Pause/Resume → Finish → summary → history

Active state is intentionally low-density. The timer and next action dominate.

## 8. TRAINING PLAN

Training → program → plan → exercise → session

The user must always know:
- what program they are following;
- what session is next;
- why this session exists;
- how to start it.

## 9. ACTIVE WORKOUT

Start session → exercise → set entry → log set → rest → next set → next exercise → finish

High-frequency controls are thumb reachable and persistent.

Set logging must support:
- weight;
- reps;
- completion;
- undo/edit;
- previous performance reference;
- rest timer.

Do not force navigation to another screen for common set operations.

## 10. SESSION SUMMARY

Finish → concise result → useful metrics → optional note → return to Today/Training

The summary should answer: what did I accomplish, how did it compare, what is next?

## 11. PROGRESS

Progress → select meaningful metric → trend → interpretation → next action

Never show a chart without an understandable takeaway.

## 12. NUTRITION

Nutrition → daily target → log food/meal → update totals → remaining target → history

The primary daily state should be understandable at a glance.

## 13. SUBSCRIPTION

Feature encounter → explain value in context → plan comparison → purchase → confirmation → return to feature

Do not use generic blocking paywalls when a contextual upgrade is possible.

## 14. SETTINGS

Profile → Settings → category → change → immediate confirmation where safe

Destructive/account actions are separated and clearly labeled.

## 15. RECOVERY

Any failed action → explain → preserve user input where possible → retry → fallback/manual route

Never dead-end.

# Claude Design execution order

## Pass 0 — Ingest
Read every file in this package. Inspect the existing Winterwork source and visual references. Do not edit yet.

## Pass 1 — Product/UX reconstruction
Reconstruct the current IA, navigation graph, feature inventory, high-frequency actions, state model and responsive constraints.

## Pass 2 — UX redesign
Fix the user journeys and information architecture. Preserve functionality. Eliminate friction.

## Pass 3 — Winterwork design system
Create the visual and component system defined in `03_UI`.

## Pass 4 — Shell and navigation
Implement the global desktop/mobile shell first.

## Pass 5 — Core daily loop
Today → action → completion → feedback → progress.

## Pass 6 — Arc / Habits / Quit / Mood / Focus

## Pass 7 — Training / Active session / Exercise / Summary

## Pass 8 — Progress / Nutrition / Profile / Settings / Subscription

## Pass 9 — All edge states
Empty / loading / error / offline / locked / success / undo / destructive / validation.

## Pass 10 — Responsive
Desktop, tablet, mobile. Never simply scale desktop down.

## Pass 11 — Motion
Use motion only to communicate state, continuity and hierarchy.

## Pass 12 — Ruthless QA
Check every route, action, state, navigation path, responsive transformation and accessibility rule.

## Stop conditions
Do not call the redesign complete if:
- a core flow is harder than before;
- an existing feature disappears;
- a primary action is ambiguous;
- a screen has no clear hierarchy;
- desktop and mobile feel like different products;
- components are visually inconsistent;
- decorative effects compete with task completion;
- any high-risk workout/habit/focus/subscription state is unaccounted for.

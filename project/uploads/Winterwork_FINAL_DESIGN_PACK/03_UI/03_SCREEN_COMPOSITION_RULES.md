# WINTERWORK — SCREEN COMPOSITION RULES

## Today

Visual priority:
1. date/phase;
2. next best action;
3. daily completion;
4. training/focus;
5. supporting insight.

Do not stack 8 equal cards.

## Arc

Make the 90-day journey emotionally legible:
- current day;
- current phase;
- completion;
- next milestone;
- what today's effort contributes to.

## Habits

Fast list. Completion is the primary interaction.

Creation/editing is secondary and should not dominate the screen.

## Focus

Immersive. Low density. Timer dominates.

## Active workout

Immersive. The current set and next action dominate. Navigation disappears.

## Progress

High density is acceptable but every section must answer a question.

## Nutrition

Daily target and remaining amount first. Details second.

## Profile/Settings

Quiet utility UI. Do not over-design settings.

## Onboarding

One question/decision at a time. Strong visual focus. Progress always visible.
